\# Data



This project uses a synthetic retail and wholesale dataset generated with Python.



The dataset represents a toy retail/wholesale business operating over approximately 2.5 years.



\## Dataset Components



The analytical model includes:



\- Date dimension

\- Product dimension

\- Customer dimension

\- Sales fact

\- Inventory fact

\- Cost fact



Additional analytical outputs include:



\- Sales forecasting results

\- Market basket association rules



\## Data Privacy



All datasets in this project are synthetic and created for portfolio and analytical demonstration purposes.



No proprietary company data or personally identifiable customer information is used.



\## Public Sample Data



A representative sample dataset will be provided in:



`data/sample/`



Large generated datasets and intermediate processing outputs are intentionally excluded from the public repository.
